# 🍝 Tapy Food — Italian Food Delivery (CSS Selectors Demo)

> A small, instructional HTML/CSS project showcasing CSS selectors, layout patterns, and a clean, food-themed UI.

- **Theme**: Authentic Italian food delivery — warm, appetizing, and hospitality-focused. 🇮🇹🍕
- **Content**: Hero banner, About section, Partner & Top restaurants, Best-seller dishes, Contact form.
- **Design language**: Minimal, card-based layout with large hero imagery, clear typographic hierarchy, and responsive grid sections.

## 🚀 At a glance

- **Purpose**: Demonstrates CSS selectors and layout techniques while presenting a fictional food delivery site called *Tapy Food*.
- **Audience**: Beginners learning HTML/CSS and reviewers wanting a quick example of semantic structure and selector usage.

## 📁 Files in this folder

- `index.html` — Main markup and semantic structure (hero, sections, articles, form).
- `styles.css` — Styling for layout, typography, grids, and component states.

## 🧩 What you'll find in the code

- Hero section with a two-column layout (image + copy) and call-to-action buttons.
- Multiple content sections using semantic elements: `section`, `article`, `header`, `main`, `footer`.
- Card-style restaurant and dish listings that use images, headings, and action buttons.
- A simple contact form with labeled inputs and a submit button.
- Responsive-friendly meta tag and grid-based layouts to adapt to different screens.

## 🎨 Design language & CSS patterns

- Color & imagery: Big hero image to set mood; content cards keep focus on imagery and short descriptions.
- Layout: CSS Grid/Flexbox to create responsive columns and card flows.
- Typography: Clear hierarchy — large headings (`h1`, `h2`) for sectioning, concise paragraphs for descriptions.
- Accessibility: Semantic HTML is used for structure; ensure `alt` text is present on images (already added in markup).

## ▶️ How to view

1. Open `index.html` in your browser (double-click or right-click → Open with Browser).
2. Inspect the page with dev tools to explore CSS selectors and rules in `styles.css`.

## ✍️ Suggested tweaks (easy experiments)

- Change hero image or heading copy to see visual impact.
- Modify card spacing, border-radius, or box-shadow in `styles.css` to explore visual hierarchy.
- Replace remote images with local assets to test loading and layout changes.
